# Bluemoji Downloader
Scrapes and downloads every color/variant of the blue emojis from [bluemoji.io](https://bluemoji.io/)

![Wearing Shades Blue Emoji](https://bluemoji.io/cdn-proxy/646218c67da47160c64a84d5/66b3ebb4e15ae36942b44682_17.png)

## Requirements
A JavaScript runtime like [Node.js](https://nodejs.org/) or [Bun](https://bun.sh/)

## Usage
Just run `index.js` with your runtime, eg. `node index.js`
